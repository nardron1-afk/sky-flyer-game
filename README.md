# Sky Flyer

A mobile-friendly arcade plane game in a single self-contained `index.html` (HTML5 canvas + vanilla JS, no assets).

**Play:** https://nardron1-afk.github.io/sky-flyer-game/

## Controls
- **Phone:** tap to start, then drag up/down anywhere to steer (relative drag, so your finger never covers the plane).
- **Desktop:** Arrow Up/Down or W/S (or click-drag the mouse). Space/Enter to start/restart, M to mute.

## Gameplay
Fly right through an endless sky. Collect coins (+25) and fuel cans (+40 fuel); fuel constantly drains. Dodge bird flocks, enemy planes (some home in on you), lightning storm clouds, rising balloons and the rolling mountains. Speed and obstacle density ramp up over time; the sky cycles day -> sunset -> night -> dawn. Best score is saved in localStorage.
